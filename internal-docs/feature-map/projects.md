# Projects

Creating and entering a project, its header and info, and its files.

## Sub-features

- project-create: `New project` asks for a name and creates the project with `Create`.
- project-list: the `Projects` tab on the [start screen](agent-home.md) lists projects, filtered by `Search projects...`; choose one to enter it.
- project-row-actions: a project row offers `Reveal in vault`, `Edit project`, `Archive`, and `Delete`; deleting keeps the notes in the vault.
- project-enter: inside a project, the start screen reads `Chat in <project>` and lists only its chats; it has its own [chat tabs](chat-tabs.md).
- project-header: the header shows the project's name and `Leave project`.
- project-info: `Project info for <project>` shows `Progress` on the agent's plan, `Edit project`, and `Reveal project folder in vault`.
- project-files: `Project files` lists `AGENTS.md` and the project's files to open, and `Outputs`.
- project-context: the project's `Context` takes files and folders dragged in, `Add a web / YouTube link`, and `Manage`.

Only the sub-features are mapped so far, and they may not cover everything this feature does. To map the rest, follow [`FEATURE_MAP_GUIDE.md`](../FEATURE_MAP_GUIDE.md).
