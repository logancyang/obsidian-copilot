# Agent setup

Choosing and installing an agent, signing in, and its default model and effort.

## Sub-features

- setup-select: when no agent is ready, Agent Chat shows `Select your agent`, each with a status such as `Installed`, `Update required`, or `Sign in required`, then `Start chat` or `Configure`.
- setup-configure: `Configure <agent>` sets up the agent's installation, `Managed by Copilot` or `My own installation`, with `Download & install` or `Update`.
- setup-sign-in: `Sign in with your browser` or `Sign in using a terminal instead`; once signed in, `Signed in as <account>.` and `Sign out`.
- setup-default-agent: Settings `Default agent` picks the agent new chats start with; picking another agent's model in a chat also changes it.
- setup-default-model: each agent's `Default model` and `Default effort` for new chats.
- setup-models: each agent's model list switches models on or off, with `Search <agent> models…`.
- setup-notification: `Notification` plays a `Sound` when an agent finishes a turn.

Only the sub-features are mapped so far, and they may not cover everything this feature does. To map the rest, follow [`FEATURE_MAP_GUIDE.md`](../FEATURE_MAP_GUIDE.md).
