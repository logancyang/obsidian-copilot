# Chat input

The box at the bottom of the chat where the user writes and sends a message: model, effort, and mode pickers, mentions, note context, images, send, and stop.

## Sub-features

- input-send: type a message and press Enter or `Send`. While the agent works, typing a draft turns `Stop generating` into `Send`, which [queues the message](queued-messages.md).
- input-stop: `Stop generating` or Escape stops the agent's reply.
- input-mentions: `@` lists Notes, Web tabs, and Folders; `Add context` (**+**) also offers Files. A mentioned note shows as a pill in the text only and is still sent as context; badges show only what was attached, in the chat input and on the sent message, and removing a badge leaves the text unchanged. Mentioning the active note does not switch its `Current` badge on. A sent message draws a mentioned folder as a `{Parent/Folder}` pill in its text. `@` and `[[` suggest no files or folders from the Copilot folder except the projects folder and what the user keeps in each project, and never a project's `project.md`.
- input-agent-mentions: with a Supporter license, `@` lists `Teammates` first, above Notes and the other context. Choosing it lists the vault's teammates, each with its face, name and title, and typing filters them by name. Typing after `@` without choosing a category lists the teammates whose name matches above the matching notes and folders. A teammate's own chat leaves that teammate out, and `Teammates` is not listed when no other teammate is left; a Copilot chat lists every teammate. A picked teammate shows as a pill with its face, and the sent message draws it the same way. A teammate's name typed after `@` counts as a mention too; a draft restored after switching chats keeps the mention as `@Name` text. The teammate you are chatting with, or Copilot, then asks that teammate, as [asking a teammate](asking-a-teammate.md) describes.
- input-locked-agents: without a Supporter license, the `@` list starts with `Teammates` and a smaller `Supporter preview`, with a lock in place of the arrow. Choosing it checks the license, then opens the "Build your AI team with Copilot Teammates" dialog and puts nothing in the message; its `See plans` opens the pricing page. If the license is now valid, the row opens the teammates instead. In a vault with teammates, the same row opens the same dialog as the locked `New` on the [start screen](start-screen.md): "This vault has <n> teammates" with `Enter license key` as the main button. Typing a name after `@` lists the matching teammates greyed with a lock above the matching notes; choosing one puts nothing in the message and opens that same dialog.
- input-needs-setup-agent: in the `@` list, a teammate whose model can't run on this device is greyed with a lock. Choosing it closes the list, puts nothing in the message, and opens its [profile](teammate-profile.md) with the reason.
- input-needs-setup-agent-chat: a chat with a teammate whose model can't run on this device opens read-only: in place of the chat input, "You can read this chat, but <name> can't reply. <reason>" with `New Copilot chat` and `Open <name>'s profile`. Choosing an old chat in `Recent chats` or the chat history whose agent isn't set up on this device opens the teammate's profile, with the reason, instead of the chat.
- input-locked-agent-chat: without a valid Supporter license, a teammate's chat from before opens read-only: in place of the chat input, "You can read this chat, but <name> can't reply without a valid Supporter license." with `New Copilot chat` (a new Copilot chat in the tab, without this conversation) and `Enter license key` (opens the license field in Copilot settings). Its `remembered` cards still open its `MEMORY.md` and `instructions.md`, and its `@` cards still open their conversation read-only. A reply already running when the license stops being valid finishes first, and a teammate asked before then still brings its reply back.
- input-current-note: the open note or web tab shows as a `Current` badge that the user can remove.
- input-selection: text selected in a note shows as a badge with the text and its line, such as `L3`, and stays highlighted in the note while the chat has focus; text selected in a [turn diff](turn-diffs.md) or a web page shows as a `Selection` badge.
- input-images: paste or drop images to attach them; `Remove image` takes one off.
- input-files: drop a note from the file explorer or a Copilot list such as [Relevant Notes](relevant-notes.md), drop a file of any type from the computer, or pick one through `Files`, to add it as context. A file from outside the vault is copied to the attachment folder first, or to the project's `sources/` folder inside a [project](projects.md); one notice per drop names the copies and their folder. A folder dropped from the file explorer, or picked through `Add context` > Folders, shows as a badge and is listed to the agent by its vault path, like a note.
- input-commands: `/` lists `compact` ("Summarize this chat to free up context"), the agent's skills, and custom commands.
- input-model-effort: `Model · effort` lists models grouped by agent, with an Effort slider; the choice applies when the picker closes.
- input-mode: `Mode` picks `Safe`, `Plan`, or `Auto`; Shift+Tab cycles through them.

## How to get to it

- At the bottom of the chat, on the [start screen](start-screen.md) and in every chat. Open Copilot Chat from the ribbon icon or the `Open Copilot Chat window` command.
- The `Add selection to chat context` and `Add web selection to chat context` commands add the current selection.

## Driving it

- Send: type a message and choose `Send`. The message shows in the conversation and the [reply](replies.md) streams below it.
- Stop: send a task that keeps the agent busy, then choose `Stop generating`. The reply stops and `Worked for <time>` shows.
- Escape: send another long task and press Escape in the chat input. The reply stops.
- Draft while working: while the agent works, type text. `Stop generating` becomes `Send`.
- Mentions: type `@`. Notes, Web tabs, and Folders are listed. Type part of a note name and press Enter. The note shows as a pill in the text and no badge is added. Attach the same note through `Add context`, then remove its badge: the pill stays in the text.
- Teammate mentions: with a Supporter license and teammates Coco, Maya and Leo, in Coco's chat type `@`. `Teammates` is the first row, and no teammate is listed. Choose it: Maya and Leo are listed, with their faces and titles; Coco is not. Type `le`: only Leo stays. Press Enter: a pill with Leo's face shows in the text, and after sending, the message shows the same pill. Type `@le` without choosing a category: Leo is listed above the matching notes. In a Copilot chat, `Teammates` lists Coco too. In a chat with a teammate when the vault has no other teammate, `@` has no `Teammates` row.
- Locked teammates: without a Supporter license, type `@` in a chat. `Teammates` with `Supporter preview` is the first row, with a lock. Choose it: the "Build your AI team with Copilot Teammates" dialog opens and the message keeps only what was typed. `See plans` opens the pricing page. Enter a Supporter license: `Teammates` has an arrow and lists the teammates.
- Locked teammates in a vault with teammates: without a Supporter license, type `@`: `Teammates` with `Supporter preview` is the first row, with a lock, and no teammate is listed. Choose it: "This vault has <n> teammates" opens with the vault's faces and `Enter license key` as the main button; with no license key on the device, the same dialog opens. Type `@ma`: Maya is listed greyed with a lock above the matching notes; choosing her opens the same dialog.
- Needs setup: turn off a teammate's model in Copilot's model settings. Type `@` in another chat: that teammate is greyed with a lock; choose it and its profile opens with the message keeping only what was typed. Open that teammate's chat from `Recent chats`: the read-only note names the model; `Open <name>'s profile` opens the profile, and picking another model there brings the chat input back.
- Locked teammate chat: start a chat with a teammate while the Supporter license is valid, then remove the license key and open that chat from `Recent chats`. The messages show, with their `remembered` cards and the `Message from` cards of teammates it asked, the chat input is replaced by the read-only note, and `New Copilot chat` opens a new Copilot chat in the tab. Enter a Supporter license: the chat input comes back without a reload.
- Copilot files: with a saved chat, a custom command, and a project holding a note, type `@` then part of each name, and `[[` then the same. The project's note is listed; the saved chat, the custom command, and the project's `project.md` are not.
- Add context: choose `Add context` (**+**). Notes, Web tabs, Folders, and Files are listed.
- Current note: open a note beside Copilot Chat. A badge with its name and `Current` shows above the text.
- Selection: select a line in that note. A badge with the selected text and its line (`L3`) shows next to the `Current` badge. Click the chat input: the line stays highlighted in the note. Remove the badge: the highlight goes away.
- Images: paste an image into the chat input. A preview shows above the text; `Remove image` takes it off.
- Files: drop a `.csv` file from Finder onto the chat input. A copy appears in the attachment folder, a notice reads `Copied <file> into <folder>/`, and its badge shows above the text. Drag a note from the file explorer onto the chat input: its badge shows and nothing is copied. Drag a nested folder from the file explorer onto the chat input: its badge shows above the text, the message text is unchanged, and the sent message shows the folder badge.
- Commands: type `/`. `compact` is listed first with "Summarize this chat to free up context", followed by skills.
- Model and effort: choose `Model · effort`. Models are grouped under each agent (OPENCODE, CLAUDE, CODEX), the current one checked, with an Effort slider below. Pick another model of the same agent and close the picker; the button shows the new model.
- Mode: choose `Mode`. `Safe`, `Plan`, and `Auto` are listed with a line each. Press Shift+Tab in the chat input; the button moves from `Auto` to `Safe`, then `Plan`, then back to `Auto`.

## Gotchas

- Picking another agent's model in `Model · effort` replaces the chat in the tab with a new chat on that agent, and that agent becomes the default for new chats. Other agents' models are listed only until a message is sent. A chat opened with `Continue from here in a new chat` lists them too until its first message; switching it keeps its messages, title and single chat note, and reopening it from Recent chats before that message opens it on the agent and model picked.
- A chat reopened from Recent chats or [Copilot Navigator](copilot-navigator.md), after `Shut down` or an Obsidian restart, comes back on the model and effort of its last reply, not the agent's `Default model`.
- While the agent works, Escape in the chat input stops the reply even when a draft is typed.
- A selection made in reading view keeps its badge but is not highlighted in the note once the chat has focus.
- Only suggestions skip Copilot's own files: a note link typed in full, a dropped file, and the `Active Note` row still attach one.
- A file dragged from Finder that is already in the vault is attached where it is, not copied. One drop can carry notes and outside files together; each is attached. A folder from outside the vault can't be added: dropping one shows a notice.
- The locked `Teammates` row shows only in Copilot Chat, never in Quick Chat. It shows for every license that is not a valid Supporter license, and with no license key. With no license key, choosing it sends nothing to Brevilabs.
