# Relevant Notes

Notes related to the current note or chat, in the start screen's shelf or in a standalone pane.

## Sub-features

- rn-source: `Relevant to` names what the list is about: the open note, or `Agent chat context` after the user works in Agent Chat.
- rn-list: related notes ranked by similarity, with a percentage and `Outgoing link` or `Backlink` marks.
- rn-preview: hovering a note shows a preview with its `Similarity`.
- rn-add-to-chat: `Add to chat` attaches the note to the current chat.
- rn-open: `Open note` or the note's title opens it.
- rn-live: the `Live` switch re-ranks the notes while the user writes.
- rn-pane: `Open in separate pane` in the [start screen](agent-home.md)'s shelf, or the `Open Relevant Notes` command, opens the standalone pane.
- rn-miyo: without Miyo, the list offers `Add semantic matches with Miyo`; other Miyo states explain why there are no matches.

Only the sub-features are mapped so far, and they may not cover everything this feature does. To map the rest, follow [`FEATURE_MAP_GUIDE.md`](../FEATURE_MAP_GUIDE.md).
